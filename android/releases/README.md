# Установить «Мои книги»

Актуальный файл: **[PortalBooks-1.3-install.apk](PortalBooks-1.3-install.apk)**.

Это цельный подписанный тестовый APK для Android 8.0+, телефона и планшета. После установки в списке приложений появится **«Мои книги»**. Сервер уже задан: `https://qicko.ru/`.

Самостоятельная сборка из папки `android`: `./gradlew assembleInstallable` (Windows: `.\gradlew.bat assembleInstallable`). Команда проверяет подпись и стартовую Activity перед экспортом установочного файла. Подробности: [Android](../../docs/ANDROID.md).

Предыдущие `*-debug.apk` сохранены для сравнения версий. Неподписанные release APK удалены из этой папки, чтобы их нельзя было перепутать с установочными. Для RuStore нужен release с ключом владельца: [инструкция](../../docs/RUSTORE.md).
