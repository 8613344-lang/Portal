# Установить «Мои книги»

Актуальный файл для первой публикации: **[PortalBooks-1.5-rustore.apk](PortalBooks-1.5-rustore.apk)**.

Это цельный release APK для Android 8.0+, телефона и планшета с постоянной подписью. После установки в списке приложений появится **«Мои книги»**. Сервер уже задан: https://qicko.ru/. Рядом находятся SHA-256 и открытый отпечаток сертификата.

Сборка из папки Portal: android/build-rustore.ps1. Скрипт требует постоянный ключ и проверяет APK перед экспортом. [Подробная инструкция](../../docs/RUSTORE.md).

Предыдущие `*-debug.apk` сохранены для сравнения версий. Неподписанные release APK удалены из этой папки, чтобы их нельзя было перепутать с установочными. Для RuStore нужен release с ключом владельца: [инструкция](../../docs/RUSTORE.md).
