# Android «Мои книги»

Текущая версия **1.5 / 6**, пакет **ru.portal.books**, Android 8.0+. APK для телефона и планшета: [PortalBooks-1.5-rustore.apk](../android/releases/PortalBooks-1.5-rustore.apk). Подписан постоянным ключом первой публикации.

## Установка

1. Разверните актуальный сайт по [DEPLOYMENT.md](DEPLOYMENT.md): нужны новые app-метаданные, конфиденциальность, удаление аккаунта и PDF-экспорт.
2. Установите release APK. Если прежний debug подписан другим ключом, удалите его перед установкой. Сбросятся локальные загрузки/вход, серверные книги сохранятся.
3. После успешной установки нажмите «Открыть» или найдите **«Мои книги»** в списке приложений.
4. Адрес уже задан — https://qicko.ru/. Персональные книги после входа идут перед публичными; нажатие открывает просмотр и авточтение.

В приложении нет заказов или админки. Регистрация и восстановление открываются в браузере. Внутри доступны конфиденциальность и удаление обычного аккаунта с паролем/подтверждением.

## Без интернета

1. Откройте доступную книгу онлайн.
2. Нажмите **«Сохранить PDF»** в нативном меню, подтвердите.
3. Откройте **«Без интернета»**. Сохранённая книга читается нативным PdfRenderer без WebView/сети.
4. Листайте кнопками; позиция запоминается. Загрузку можно удалить.

Офлайн — PDF с текстом и иллюстрациями, **без аудио**, до 100 МБ на книгу. Файлы находятся во внутреннем хранилище, не в общей папке Downloads. Персональные копии очищаются при выходе/смене аккаунта. Отзыв доступа на сайте не удаляет уже сохранённую копию; об этом предупреждает подтверждение сохранения.

На старом сервере без метаданных аккаунта сохранение выключено. Сначала обновите сайт. Приватный PDF скачивается с серверной проверкой доступа и текущей сессионной cookie; cookie не сохраняется в офлайн-индексе.

## Телефон и планшет

Режим выбирается автоматически: минимальная ширина от 600 dp — планшет. Онлайн поддерживает одиночные листы и развороты. Офлайн PDF вписывается в экран.

Android «Назад» возвращает из офлайн-книги к загрузкам, из онлайн-книги — к полке. При сворачивании онлайн-аудио и таймер приостанавливаются.

## Сборка

Версия 1.5 исправляет масштабирование и дублирование разворотов в старых WebView. В нативном меню есть «Видео»: сборка и просмотр MP4, сохранение через системный выбор файла. При чтении, включая офлайн PDF и видео, экран остаётся включённым; сворачивание снимает удержание. [Видео и серверная очередь](VIDEO.md).

Нужны JDK 17 или совместимая JDK Android Studio, SDK Platform 35, Build-Tools 35.0.0. Wrapper 8.11.1 и AGP 8.9.1 включены.

Для магазина из Portal:

~~~powershell
.\android\build-rustore.ps1
~~~

Для разработки из android:

~~~powershell
.\gradlew.bat assembleInstallable lintDebug
~~~

Файл -install.apk предназначен для проверки; для магазина используется **-rustore.apk** с постоянной подписью. Release без ключа блокируется; assembleRuStore отвергает Android Debug, debuggable и testOnly.

Подробно: [RUSTORE.md](RUSTORE.md), [SIGNING.md](SIGNING.md).

## Диагностика

При ошибке сети/HTTPS или сбое WebView есть нативный экран повторной загрузки. «Без интернета» остаётся доступным. Для онлайн-чтения обновите Android System WebView/Chrome; ошибки сертификатов не обходятся.

Если установка не завершилась или «Открыть» неактивна, сохраните сообщение, модель и версию Android. Проверка SDK:

~~~powershell
adb install -r android/releases/PortalBooks-1.5-rustore.apk
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.LAUNCHER -p ru.portal.books
adb shell am start -W -n ru.portal.books/.MainActivity
adb logcat -b crash -d
~~~

Ожидаются Success и ru.portal.books/.MainActivity. Android TV не заявлен.

## Серверные изображения и статистика

Android 1.5 использует адаптивные WebP-копии обложек и страниц с сервера, без обновления APK. В серверной статистике фиксируются посещения и открытия/переходы книги, IP, пользователь при входе и доступные сведения User-Agent. Новых SDK, разрешений и аналитических cookies нет.
