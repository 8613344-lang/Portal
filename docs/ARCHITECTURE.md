# Архитектура

```text
Браузер → HTTPS :443 → Caddy → Gunicorn / Django :8000
                                  ↓              ↓
                            PostgreSQL       private_media
Заказ + Notification (одна транзакция) → worker → SMTP / Telegram Bot API
```

Gateway не имеет доступа к приватным файлам. Django проверяет право и затем отдаёт поток файла. Для аудио реализованы одиночные Range и HEAD. Защищённые ответы не попадают в общий кеш.

## Данные и масштабирование

`Book` — метаданные, slug, состояние и видимость. `BookPage` — позиция, текст, иллюстрация и MP3/WAV. `BookAccess` — уникальная пара книга/читатель. `Order` — UUID, контакт, ребёнок, тема, фото, согласие, менеджер, состояние и готовая книга. `NotificationRecipient` — канал/адрес/активность и связанный сотрудник для Telegram. `Notification` — состояние, попытки, срок следующей попытки и аренда задачи. `BotState` — offset Telegram. `RateEvent` — ограничение частоты запросов.

Каталог выводит по 18 книг, используются индексы и уникальные ограничения. Общий просмотрщик читает одну книгу и отображает одну страницу; остальные иллюстрации заранее не загружаются. Число книг не равно числу процессов. Ёмкость сервера зависит от файлов и одновременных читателей; нагрузочное измерение на целевом сервере ещё требуется.

## Выгрузки и автоматическое чтение

`/books/<slug>/download/pdf/` и `/books/<slug>/download/mp3/` повторяют проверку `visible_to` до чтения файлов. Ответы имеют `private, no-store`; файлы создаются только во временном хранилище на время запроса и ответа. PDF строится ReportLab со встроенным лицензированным DejaVu Serif, фоном, обложкой и финальным QR-кодом на `SITE_URL`. Текст экранируется перед передачей в разметку PDF. Canvas-верстка PDF фиксирует один лист A4 на страницу книги: крупная иллюстрация высотой до 112 мм, текст в оставшейся области с измерением того же Paragraph перед отрисовкой. Шрифт подбирается от 14 до 9 пунктов. Невмещающийся текст приводит к ExportError, а не переносу или усечению.

MP3/WAV страниц декодируются FFmpeg в одинаковый PCM (44,1 кГц, стерео), затем объединяются и один раз кодируются в MP3 192 кбит/с. Это позволяет объединять разные входные форматы. Отсутствующие записи пропускаются с указанием числа озвученных страниц. Ограничения: 100 секунд, 1 ГБ PCM, две одновременные сборки на процесс; ошибки не выдают обрезанный MP3. Экспорт пока не вынесен в отдельную очередь.

Авточтение работает в одном документе: клиент получает следующую страницу отдельным авторизованным запросом и заменяет страницу, аудио и навигацию. Переход запускается событием `ended` записи; для страниц без аудио используется настраиваемый таймер. Пауза отменяет таймер и незавершённый запрос. Ошибки аудио и доступа останавливают чтение; синтеза речи нет.

## Права

Публичная книга доступна всем только в `published`. Закрытая — зарегистрированному пользователю с явным `BookAccess`, также в `published`. Регистрация сама не выдаёт доступ.

Активный сотрудник с `view_book` видит все книги и черновики, `change_bookpage` нужен для изменения озвучки. Админка применяет стандартные права Django. Группы создаются через `setup_groups`; флаг `is_staff` сам не даёт всех прав.

Фото заказа доступно только сотрудникам с `view_order`, включая прямой URL. Заказчик видит собственный статус, но исходное фото не публикуется. Отсутствие объекта и отсутствие права возвращают одинаковый 404. Отзыв доступа блокирует новые запросы, но не удаляет ранее скачанные файлы или данные из памяти браузера.

## Файлы

Изображения: JPEG/PNG/WebP, до 10 МБ и 25 мегапикселей. Они декодируются, поворачиваются по EXIF, преобразуются в JPEG до 2400×2400 без исходных метаданных. SVG/HTML не принимаются. Аудио: MP3/WAV до 100 МБ; Mutagen проверяет реальный формат и продолжительность. Имена файлов — случайные UUID. Закрытое медиа не раздаётся как статический каталог.

Файловые операции не являются частью транзакции базы. После сбоя или замены вложения могут остаться неиспользуемые файлы; они не доступны по HTTP без текущей привязки в базе. При удалении данных учитывайте приватное хранилище и резервные копии.

## Уведомления

Получатели задаются до заказа. Каждому активному разрешённому получателю создаётся отдельная задача. Если получателей нет, заказ всё равно сохраняется; задачи для него автоматически не появляются позднее.

Worker арендует задачу на 5 минут и делает сетевой вызов вне транзакции. Сбой возвращает её в очередь с увеличенной задержкой; после восьми попыток возникает `failed`, повтор доступен в админке. Отзыв прав/отключение получателя отменяет ожидающие отправки. Изменение адреса отменяет старые задачи вместо неожиданной пересылки.

Доставка — **at least once**: при аварии после отправки, но до записи результата, возможно повторное уведомление с тем же UUID заявки. SMTP/Telegram не имеют общей транзакции с нашей базой. Идемпотентность формы защищает сам заказ токеном сессии и уникальным ограничением базы.

Бот работает через long polling без входящего webhook. Запускайте один опрашивающий worker. Проверяются числовой личный ID, `is_active`, `is_staff` и `view_order`; групповые чаты не обслуживаются. `/orders` возвращает до пяти UUID/защищённых ссылок без имён детей и фото. Ошибки записываются как тип исключения, без URL с токеном.

## Эксплуатация

Настройте SMTP, Telegram и получателей; проверьте доставку тестовой заявкой. Подготовьте домен/доверенный локальный сертификат, сотрудников и читателей, бэкапы и восстановление. Укажите реквизиты владельца, контакт для удаления данных и срок хранения в политике сайта.

Демонстрационная книга перенесена из `8613344-lang/Dima`, исходный коммит `4c94a3c`. Новые книги и записи загружаются владельцем платформы; автоматической генерации книги здесь нет.

В режиме «Только страница» CSS скрывает оболочку сайта; ResizeObserver и событие загрузки иллюстрации подбирают масштаб текущей страницы под окно. При перелистывании наблюдатель переключается на новый элемент. Управление доступно через скрывающуюся панель, Esc и пробел; озвучка и проверка доступа остаются прежними.

PDF layout/background stored in Book; background image uses the same private media access checks. `pdf_full_page` marks imported facsimile pages, which bypass layout reflow to preserve the source. PDFium renders staged JPEG files under a per-process mutex; input limits are 100 MB / 100 sheets / 90 seconds. Import commits pages atomically and removes stored images on write failure. Original PDF is not retained or publicly served. Source text layers are copied, scans require a separate OCR workflow if editable text is needed.
