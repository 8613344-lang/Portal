# Оформление сайта

Обновлён публичный сайт, каталог, личная полка и оформление форм. Кремовый фон, горчичные кнопки, небесные и лавандовые панели, русские подписи и системный шрифт с поддержкой кириллицы. Внешние шрифты и библиотеки анимации не загружаются.

## Главная страница

- Раскрытая книга с детским фото в рамке, мягкое движение книги и световой эффект перелистывания.
- Баннер «Скидка на создание книги сейчас!» с ненавязчивым бликом. Процент, срок и стоимость не придуманы: детали заказа обсуждаются после заявки.
- Три карточки: одна опубликованная публичная книга и две явно обозначенные идеи оформления. Если публичных книг пока нет, первая карточка также показывает идею. Идеи ведут к форме заказа; настоящая книга — в просмотрщик.
- Превью личной полки явно помечено как пример. Реальные персональные книги видны в кабинете согласно выданным доступам.
- Адаптивное меню, клавиатурное управление и отключение анимации при системной настройке уменьшения движения.

## Аудиопревью

Плеер получает существующую запись опубликованной публичной книги: сначала аудио обложки, затем запись страницы. Закрытые, черновые и архивные книги не используются, в том числе при просмотре главной администратором. Синтез речи не применяется.

Если записи нет, кнопка неактивна, рядом написано «Аудиопример пока не добавлен». Загрузите MP3 или WAV к обложке либо странице публичной опубликованной книги через админку, и превью станет доступно. Воспроизведение начинается по нажатию; волны двигаются только во время воспроизведения. Ошибка файла отображается в плеере.

## Исходники и иллюстрации

- `static/site.css`, `static/site.js` — общая тема сайта, главная, меню и аудиоплеер.
- `static/library-design.css` — каталог, кабинет и карточки.
- `templates/base.html`, `templates/library/home.html`, `catalog.html`, `account.html`, `book_card.html` — страницы.
- `static/images/` — WebP-иллюстрации. Точные промпты и происхождение: [ARTWORK.md](../static/images/ARTWORK.md).

Тема подключается только к сайту через `base.html`. Android использует отдельный `app_base.html`. Проверены переход в «Только страница», скрытие шапки/подвала и ручное перелистывание; выбранный цвет текста последней страницы сохраняется.

## Установка обновления

Схема базы не меняется. Для существующей установки Docker:

```bash
git pull --ff-only
docker compose up -d --build
```

Для запуска без Docker соберите статические файлы в окружении приложения и перезапустите веб-процесс:

```bash
python manage.py collectstatic --noinput
```

После обновления обновите страницу браузера. Полная настройка сервера описана в [README](../README.md).

## Проверка

78 Django-тестов, в том числе четыре проверки выбора публичного аудиопревью. В браузере проверены главная, каталог, заявка, вход и регистрация на ширинах 360, 390, 820 и 1440 пикселей, мобильное меню, уменьшение движения, кабинет и режим чтения. Заявки и письма при визуальных проверках не отправлялись.
