# Оформление сайта

Обновлён публичный сайт, каталог, личная полка и оформление форм. Кремовый фон, горчичные кнопки, небесные и лавандовые панели, русские подписи и системный шрифт с поддержкой кириллицы. Внешние шрифты и библиотеки анимации не загружаются.

## Главная страница

- Раскрытая книга с детским фото в рамке, мягкое движение книги и световой эффект перелистывания.
- Баннер «Скидка на создание книги сейчас!» с ненавязчивым бликом. Процент, срок и стоимость не придуманы: детали заказа обсуждаются после заявки.
- Три карточки: одна опубликованная публичная книга и две явно обозначенные идеи оформления. Если публичных книг пока нет, первая карточка также показывает идею. Идеи ведут к форме заказа; настоящая книга — в просмотрщик.
- Превью личной полки явно помечено как пример. Реальные персональные книги видны в кабинете согласно выданным доступам.
- Адаптивное меню, клавиатурное управление и отключение анимации при системной настройке уменьшения движения.
- На телефоне баннер скидки использует отдельную строку для кнопки; длинный текст переносится, не сжимая содержимое в узкий столбец.
- Кнопка «Начать просмотр» выделена тёплым цветом и мягким пульсом тени.

## Аудиопревью

Кнопка «Сказку можно слушать» раскрывает пять вариантов, которые администратор настраивает в разделе «Варианты озвучки»: название, запись MP3/WAV до 100 МБ и включение варианта. Номера 1–5 задают порядок. Вариант без записи или с выключенным переключателем остаётся видимым, но не воспроизводится. Синтез речи не применяется; записи книг не подставляются автоматически.

Выбор доступного варианта запускает запись, круглая кнопка позволяет поставить её на паузу и продолжить. Одновременно воспроизводится одна запись; волны двигаются только во время воспроизведения. Список закрывается по Escape, нажатию снаружи и кнопке закрытия; на небольшом экране он остаётся в пределах окна. Ошибка файла отображается в плеере. Аудиопримеры включённых вариантов доступны публично через отдельный маршрут с поддержкой Range/HEAD; закрытые материалы книг по-прежнему требуют разрешения.

## Текст скидки

В разделе админки «Скидка на главной» редактируются три строки баннера: «Надпись над заголовком», «Заголовок скидки» и «Текст скидки». Переносы строк описания сохраняются, HTML выводится как текст. После сохранения главная использует новый текст без перезапуска процесса. Начальные значения соответствуют прежнему баннеру.

## Исходники и иллюстрации

- `static/site.css`, `static/site.js` — общая тема сайта, главная, меню и аудиоплеер.
- `static/audio-preview.css` — выпадающий список пяти вариантов озвучки.
- `static/library-design.css` — каталог, кабинет и карточки.
- `templates/base.html`, `templates/library/home.html`, `catalog.html`, `account.html`, `book_card.html` — страницы.
- `static/images/` — WebP-иллюстрации. Точные промпты и происхождение: [ARTWORK.md](../static/images/ARTWORK.md).

Тема подключается только к сайту через `base.html`. Android использует отдельный `app_base.html`. Проверены переход в «Только страница», скрытие шапки/подвала и ручное перелистывание; выбранный цвет текста последней страницы сохраняется.

## Установка обновления

Миграция `0009_homepage_settings` создаёт настройки баннера и пять пустых вариантов озвучки. Для существующей установки Docker (миграции выполняются при запуске):

```bash
git pull --ff-only
docker compose up -d --build
```

Для запуска без Docker соберите статические файлы в окружении приложения и перезапустите веб-процесс:

```bash
python manage.py migrate
python manage.py collectstatic --noinput
```

После обновления обновите страницу браузера. Полная настройка сервера описана в [README](../README.md).

## Проверка

109 Django-тестов, в том числе 20 проверок пяти вариантов озвучки, прав доступа и текстов скидки. В браузере проверены главная, каталог, заявка, вход и регистрация на ширинах 360, 390, 820 и 1440 пикселей, меню, уменьшение движения, кабинет и режим чтения. Список озвучек дополнительно проверен на ширинах 320 и 1024 пикселя: все пять вариантов помещаются в окно. На тестовых WAV проверены воспроизведение, переключение, пауза, завершение и восстановление после ошибки. Заявки и письма при визуальных проверках не отправлялись.

## Книжная полка на сайте

Дополнительный режим `/shelf/` показывает персональные книги, затем публичные, без повторов. В меню и каталоге есть ссылка «Книжная полка». Права совпадают с приложением: видны только опубликованные книги, назначенные пользователю, и публичные истории; чужие закрытые книги и черновики недоступны. Полки имеют отдельную пагинацию. Нажатие на обложку сразу запускает просмотр с авточтением; кнопка возврата и Escape возвращают на полку. Обычный каталог продолжает работать отдельно.
