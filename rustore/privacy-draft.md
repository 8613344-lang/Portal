# Данные Qicko — заготовка для заполнения владельцем

Не публиковать с незаполненными полями.

Владелец/оператор: [ФИО или организация, необходимые реквизиты]. Контакт для обращений: [email и способ связи]. Сайт: https://qicko.ru/. Сроки хранения и порядок удаления: [заполнить фактический порядок].

Для аккаунта используются email и отображаемое имя. Имя может совпадать у разных пользователей; email служит для входа, подтверждения и восстановления. Сервер хранит хеш пароля, сведения подтверждения, сессию и предоставленные пользователю доступы. В форме регистрации запрашивается согласие и капча.

Персональные книги показываются только в соответствии с выданными доступами. Ссылка прямого просмотра с QR даёт доступ любому получателю этой ссылки; владелец книги должен учитывать это при её передаче. Публичная публикация книги — отдельное решение администратора, которое требует согласования по правилам платформы.

Android-клиент подключается к серверу онлайн и использует сессионные cookies. Он не запрашивает камеру, микрофон, геолокацию и контакты, не содержит рекламных и аналитических SDK. SMTP-провайдер доставляет коды подтверждения и письма восстановления: [указать используемого провайдера и применимый порядок обработки].

В мобильной веб-версии браузер хранит в localStorage срок скрытия предложения добавить ярлык (семь дней после закрытия, 90 дней после подтверждения установки). Эта настройка не отправляется на сервер. Service worker кэширует только общую страницу сообщения об отсутствии сети `/offline/`, без данных аккаунта и книг. Ярлык сам по себе не сохраняет книги для офлайн-чтения.

На сервере сайта ведётся техническая статистика: время и страница, IP, User-Agent, определяемые из него браузер/версия и устройство, пользователь при входе и домен источника. Для книг различаются открытие и переходы по страницам. Отдельные аналитические cookies не устанавливаются. Query string, тела форм, пароли и секретные ссылки не записываются. Доступ есть у сотрудников с правом просмотра статистики. Текущая настройка хранения — 90 дней с почасовой очисткой; при иной конфигурации укажите фактический срок. При удалении аккаунта удаляются связанные с ним записи статистики.

По явному выбору пользователя Android-приложение сохраняет PDF-копию книги и позицию чтения во внутреннем хранилище устройства. В этих копиях нет озвучки. Пользователь может удалить загрузку; при выходе или смене аккаунта локальные копии очищаются. Отзыв серверного доступа сам по себе не удаляет уже сохранённый PDF. Сессионные cookies не записываются в офлайн-индекс.

Локальная база DB-IP City Lite определяет предполагаемые город, регион и страну по IP. Адрес посетителя во внешний GeoIP-сервис не отправляется; GPS/геолокация устройства не запрашиваются. Географические сведения приблизительны. Статистика вместе с этими полями выгружается в CSV только сотрудником с соответствующим доступом. Источник: [IP Geolocation by DB-IP](https://db-ip.com), CC BY 4.0.

Позиция видеопросмотра сохраняется в браузере с разделением по аккаунтам и книгам. У вошедшего пользователя она также хранится в его аккаунте на сервере для продолжения на другом устройстве; запись удаляется при удалении аккаунта или книги. Гостевая позиция остаётся в браузере. Кнопка «Начать сначала» сбрасывает позицию; очистка данных сайта удаляет локальную копию.

Обычный пользователь может удалить аккаунт из приложения после ввода текущего пароля и подтверждения. Удаляются учётная запись, подтверждение email и выданные ей доступы. Книги и заявки сервера автоматически не уничтожаются; заявку система отвязывает от удалённого аккаунта. Отдельно определите фактический порядок удаления материалов заказа и обращений к оператору: [заполнить владельцем].

Заказы на сайте могут включать имя ребёнка, описание, пожелания и фото. Опишите отдельно работу с этими материалами, доступ сотрудников, способы обращения и удаления. Для каждого вида данных определите фактические сроки хранения; не заменяйте их неопределённым обещанием.
