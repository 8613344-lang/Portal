# Комплект Qicko для RuStore — 1.4

Загружать в магазин: **android/releases/PortalBooks-1.4-rustore.apk**.

Полная пошаговая инструкция: **docs/RUSTORE.md**.
Хранение ключа и перенос: **docs/SIGNING.md**.
Сценарий модерации: **rustore/MODERATION.md**.

APK подписан постоянным ключом первой публикации. В публичном ZIP находятся открытый отпечаток сертификата, контрольные суммы, материалы карточки и исходники Android. Закрытого ключа и пароля здесь нет.

Перед отправкой владелец должен выбрать публичное имя разработчика и email поддержки, завершить документ конфиденциальности на рабочем сайте и подготовить тестовый доступ проверяющему. Эти сведения намеренно не выдуманы.

Чтобы повторить сборку, восстановите свой ключ и выполните android/build-rustore.ps1. Старые архивы 1.1–1.3 относятся к тестовым версиям и для этой публикации не нужны.
