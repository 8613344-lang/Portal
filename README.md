# Книги рядом · Portal

Единая платформа персональных детских книг: один просмотрщик, одна база и один внешний HTTPS-порт 443. Отдельный процесс на каждую книгу не нужен.

## Возможности

- Открытая главная страница, каталог с поиском и пагинацией, примеры и форма заказа.
- Дополнительная «Книжная полка» `/shelf/`: персональные книги перед публичными, как в приложении. Нажатие сразу запускает просмотр, выход возвращает к полке.
- Раздел каталога называется «Истории наших читателей». На главной доступны пять настраиваемых вариантов озвучки и редактируемый баннер скидки.
- Регистрация, вход, смена пароля и личная полка: только опубликованные книги с явно выданным доступом.
- Страницы книг: текст, иллюстрация, необязательный MP3/WAV. Синтетической озвучки нет.
- Редактор загружает/заменяет/удаляет запись прямо на странице; аудио хранится на сервере и поддерживает перемотку.
- Админка: публикация, публичный/индивидуальный доступ, назначение читателей, страницы, заказы и менеджеры.
- Пользовательское соглашение `/privacy/`: заголовок и текст редактируются в админке и сохраняются в базе.
- Закрытые картинки, аудио и фото заказов защищены серверной проверкой доступа.
- Заказ и задачи уведомления сохраняются одной транзакцией. Фоновый процесс отправляет email и Telegram с повторными попытками.
- Бот проверяет числовой Telegram ID и действующие права сотрудника. Команды `/start`, `/help`, `/orders`; фото и полные карточки остаются в админке.
- Импорт книг из JSON. В поставке «Дима — супергерой»: 12 страниц и 10 иллюстраций исходного проекта.
- Выгрузка книги в PDF A4: обложка, иллюстрации, тёплый фон, встроенный шрифт с кириллицей и QR-ссылки на книгу и/или видео на последнем листе. Выбор при создании книги: совместный лист либо чередование полноформатной иллюстрации и листа текста.
- Общая аудиокнига MP3 из записей страниц MP3/WAV по порядку. Страницы без записи пропускаются, число записей видно перед выгрузкой.
- Автоматическое чтение: перелистывание по окончании аудио, а на страницах без записи — по таймеру 3–300 секунд. Единая кнопка «Начать просмотр» запускает просмотр и авточтение; внутри доступны пауза и ручные стрелки. Чередующийся формат показывает разворот картинки и текста.

## Технологии

Видео книги: фоновая сборка MP4 с загруженной озвучкой, приватный серверный кэш и отдельный просмотр. [Использование и worker](docs/VIDEO.md).

Django 5.2, HTML-шаблоны, небольшой JavaScript, PostgreSQL 17, Gunicorn, WhiteNoise и Caddy. Локально поддерживаются SQLite и Waitress на Windows. Закрытые тексты не включаются в JavaScript-бандл.

Docker Compose запускает `db`, `app`, `worker`, `gateway`. Только `gateway` публикует 443. Файлы хранятся в приватном постоянном volume, заявки и права — в PostgreSQL.

## Развёртывание

Подробная инструкция: **[локальный сервер, HTTPS, почта, Telegram и резервные копии](docs/DEPLOYMENT.md)**.

После настройки `.env`:

```bash
docker compose up -d --build
docker compose exec app python manage.py createsuperuser
docker compose exec app python manage.py setup_groups
docker compose exec app python manage.py seed_demo
```

Админка: `https://ваш-домен/admin/`. Локальный HTTPS требует доверия центру Caddy; для публичного домена сертификат может выдаваться автоматически через порт 443.

## Управление

1. Создайте книгу и страницы в `/admin/`, загрузите изображения и MP3/WAV.
2. Для персональной книги оставьте «Для выбранных пользователей».
3. Добавьте читателей в «Доступы к книгам», переведите книгу в «Опубликована».
4. Для каталога явно выберите «Публичная» и «Опубликована». Публикацию персональной истории предварительно согласуйте с родителем.
5. Добавьте получателей email/Telegram; Telegram требует ID и связанного сотрудника с правом просмотра заказов.
6. Назначьте в заказе менеджера, пользователя и готовую книгу. Действие «Выдать заказчикам доступ к готовым книгам» создаёт разрешения для выбранных заказов.
7. Для изменения `/privacy/` откройте «Пользовательское соглашение», выберите документ, измените заголовок и текст и нажмите «Сохранить». Изменения сразу видны на сайте. Суперпользователь имеет доступ автоматически; сотруднику нужны права просмотра и изменения пользовательского соглашения. Абзацы отделяются пустой строкой; HTML не выполняется.
8. В разделе «Варианты озвучки» настройте пять вариантов: название, файл MP3/WAV до 100 МБ и переключатель «Вариант включён». Они появятся в списке по нажатию «Сказку можно слушать». Без загруженной записи вариант недоступен; аудио книг не подставляется автоматически.
9. В разделе «Скидка на главной» измените надпись над заголовком, заголовок скидки и текст. Изменения сразу отображаются на главной после сохранения.

Гостевой заказ не привязывается автоматически по совпадению email: администратор связывает его с подтверждённым пользователем вручную.

## Проверки

```bash
python manage.py check
python manage.py makemigrations --check --dry-run
python manage.py test
```

[Архитектура](docs/ARCHITECTURE.md) · [Проверки и ручная приёмка](docs/TESTING.md).

Пароли, токены, рабочая база и пользовательские фотографии не входят в репозиторий. Копируйте `.env.example` в `.env` и задайте свои значения. GitHub-токен приложению не нужен.

При создании книги в админке можно выбрать фон (бумага, белый, мятный, небесный, розовый или своё изображение) и загрузить PDF для автоматического создания страниц. Импорт сохраняет исходный вид каждого листа; текст извлекается только из имеющегося текстового слоя, сканы не распознаются.

Подложка последнего листа имеет настраиваемые цвет и прозрачность 0–100%; цвет текста и QR задаются отдельно и применяются в просмотрщике и PDF.

## Android-приложение

[Установка и сборка Android](docs/ANDROID.md). Готовый release: [PortalBooks-1.5-rustore.apk](android/releases/PortalBooks-1.5-rustore.apk). [Комплект RuStore](rustore/qicko-rustore-kit-1.5.zip) и [пошаговая публикация](docs/RUSTORE.md). Клиент показывает персональные книги перед публичными, открывает просмотр, сохраняет PDF для нативного чтения без интернета. Поддерживаются телефон и планшет, конфиденциальность и удаление аккаунта. Ключ первой публикации хранится отдельно от Git; [резервное копирование](docs/SIGNING.md).

[Мобильный сайт и ярлык на iPhone/iPad/Android](docs/MOBILE_WEB.md): нижняя навигация, предложение установки и отдельные инструкции на `/install/`. Ярлык открывает книжную полку; при отсутствии интернета показывается общая страница без приватных данных.

Вход по email, подтверждение кодом и капча, профиль и восстановление: [Аккаунты](docs/ACCOUNTS.md). Android сразу подключается к qicko.ru. [Материалы и алгоритм RuStore](docs/RUSTORE.md).

## Поиск и индексация

Главная, заказ, описание услуги `/personalnaya-kniga/` и страницы публичных книг `/stories/<slug>/` подготовлены для поиска: индивидуальные метаданные, canonical, JSON-LD, `/robots.txt` и автоматически обновляемые карты сайта `/sitemap.xml`. Закрытые книги, QR-ссылки, кабинеты, приложение и файлы экспорта остаются noindex. [Поисковые фразы, развёртывание, Яндекс и Google](docs/SEO.md).

## Изображения и статистика

Сайт и Android используют адаптивные WebP-копии обложек, иллюстраций и фонов; оригиналы сохраняются для выгрузок. В админке доступны «Книги и идеи на главной» для выбора карточек и «Статистика посещений» с IP, пользователем, браузером, просмотрами страниц и книг. По умолчанию журнал хранится 90 дней, очистка выполняется analytics_worker. [Настройка и использование](docs/IMAGES_AND_STATISTICS.md).
